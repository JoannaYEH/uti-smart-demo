📌 系統說明

本頁面展示「院內泌尿道感染（UTI）輔助收案系統」之示範收案結果。 系統以 FHIR / TW Core 相容之結構化醫療資料 為基礎， 搭配可解釋的收案規則，引導感染管制人員快速完成個案判定。

為確保競賽展示之穩定性，本系統採用 雙軌資料策略：

  • 主要路徑（TW Core 相容）： 使用 Encounter、Observation 等 FHIR 結構化資源，作為可追溯之判斷依據。
  • 備援路徑（Demo 穩定性）： 當沙盒或網路狀況不穩時，系統仍可由 Patient.extension 中之示範資料進行判斷， 不影響功能展示。

🧭 判斷邏輯摘要

  • 依年齡區分收案邏輯（<1 歲 / ≥1 歲）。
  • 評估體溫異常、泌尿道相關症狀與其發生時序。
  • 判斷是否為導管相關感染（依導管置放天數與感染日關係）。
  • 所有判斷結果均可回溯至對應之 FHIR 資源或示範資料來源。
